\# Address Book Management System



\## Description

A contact management application developed using C programming.



\## Features

\- Add new contacts

\- Search for contacts

\- Edit existing contact details

\- Delete contacts

\- List saved contacts



\## Concepts Used

\- Structures

\- File Handling

\- Modular Programming

\- Functions



\## Programming Language

C



\## Project Structure

The project is organized into multiple source (`.c`) and header (`.h`) files.



\## Compilation and Execution

Compile the project using GCC:



```bash

gcc main.c contact.c file.c populate.c -o addressbook

```



Run the application:



```bash

./addressbook

```
